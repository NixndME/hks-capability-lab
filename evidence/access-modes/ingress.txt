Root cause of initial timeout on worker-1 (.230) and worker-3 (.233):
ingress-nginx-controller Service has externalTrafficPolicy=Local (preserves
client source IP, standard ingress-nginx default). NodePort 31992 therefore
only answers on the node that is actually running the controller pod
(worker-2 / 192.168.122.232 at test time). Traffic to that port on any other
node is silently dropped (no SNAT/redirect under Local policy) -- this is
expected behavior, not a defect. hks-lab-app-nodeport uses the default
externalTrafficPolicy=Cluster and therefore answers on all 4 node IPs.
